# 추론 과정 로봇 진동 감소 방법론

## 1. 구현 완료

| 방법 | 현재 상태 |
|------|----------|
| Chunk 간 오프셋 보정 | `--offset-correction` |
| 이동평균 / EMA 스무딩 | `--smoothing` |
| 속도 제한 (vel clamp) | `max_velocity` / `max_gripper_velocity` |
| 동적 FPS 감속 | 큐 잔량 30% 미만 시 자동 감속 |
| Temporal ensemble (weighted avg) | `--aggregate-fn` |

## 2. 추가 적용 가능한 방법

### A. 저역 통과 필터 (Low-pass filter)
매 스텝 실행 직전, 이전 실행값과 목표값을 블렌딩:
```
실제전송 = α * 목표액션 + (1-α) * 이전전송값
```
- α=1이면 필터 없음, α=0.3이면 강한 필터
- 고주파 떨림 제거에 가장 직접적. 구현도 간단
- 단점: 반응 지연 (α가 작을수록)

### B. 액션 보간 (Interpolation)
큐에서 꺼낸 액션을 즉시 보내지 않고, 이전 액션과 다음 액션 사이를 선형/스플라인 보간:
- 이산적 점프를 부드러운 곡선으로 변환
- 특히 chunk 경계에서 효과적

### C. Chunk 경계 블렌딩 (Cross-fade)
새 chunk 도착 시 이전 chunk 잔여 액션과 새 chunk를 크로스페이드:
- 현재 aggregate_fn이 하는 역할이지만, 타임스텝 겹침이 없으면 작동 안 함
- 의도적으로 chunk 요청을 일찍 보내서 겹침 구간 확보 필요

### D. Jerk 제한 (가속도 변화율 제한)
속도뿐 아니라 **가속도의 변화**도 제한:
```
가속도 = (현재속도 - 이전속도) / dt
if |가속도| > max_jerk: 클램핑
```
- 급격한 방향 전환 = 진동의 주원인. 이걸 직접 억제
- 모터 부하도 줄어듦

### E. 모터 컴플라이언스 (PD 게인 조절)
모터 드라이버 레벨에서 P/D 게인을 낮추면 기계적으로 부드러워짐:
- piper SDK에서 지원하는지 확인 필요
- 소프트웨어 필터와 달리 물리적 진동 자체를 줄임

### F. Delta action → Position action 변환 시 누적 오차 보정
모델이 delta action을 출력하면 누적 드리프트 → 진동 원인. 주기적으로 현재 위치 기준으로 리셋.

## 3. 추천 우선순위

1. **저역 통과 필터 (A)** — 1줄 코드, 즉각적 효과, α를 UI로 조절
2. **Jerk 제한 (D)** — 급방향전환 억제, 속도 제한과 함께 쓰면 시너지
3. **액션 보간 (B)** — chunk 내 부드러움 개선
